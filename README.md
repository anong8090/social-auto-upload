# 河狸云·蓝枢 Planora —— 「一稿五投」AI 自媒体全自动流水线

本项目面向团队协作设计，集成了开源自媒体分发引擎 **OmniPost** 与面向 AI Agent（如 Antigravity、Cursor、Windsurf、Claude Code 等）的自动化流水线规范（[AGENTS.md](AGENTS.md)），支持**1 个选题全自动生成双版本文案 + 6 张专版配图，并从可用平台池中随机抽取 5 个平台真实发布、回填飞书台账**。

> **现行口径（与 AGENTS.md 一致，2026-11 更新）**
> - **全自动发布**：用户已授权 Agent 直接发布（2026-11-03 起生效），不再默认停在草稿箱等人工发布；仅当次指令明确要求「只存草稿」时才走草稿流程。发布前必须过合规自检与 [REVIEW.md](REVIEW.md) 闸门，任一项不通过即中止报告。
> - **随机 5 平台**：每期从有效账号池中随机抽 5 个不同平台（知乎、百家号、今日头条、搜狐号、微博、企鹅号、百度贴吧，及已绑定的网易号/大鱼号/微信公众号）。
> - **小红书永久禁发**：小红书账号已被封禁，严禁发布、上传或保存草稿，选台时自动过滤，代码层硬拦截。
> - **统一发布入口**：日常发布走 `omnipost/scripts/publish_episode.py`，不再新建根目录一次性脚本；旧脚本已归档到 `legacy_scripts/`，仅作历史参考。

## 一、 新人同事极速上手（3 步走）

### 步骤 1：一键初始化运行环境
在 macOS 访达（Finder）中直接**双击运行 `setup.command`**（Windows 用 `setup.bat`）：
> 该脚本会自动创建 `omnipost/.venv` 虚拟环境、安装 Python 依赖库并下载 Chromium 浏览器内核。

### 步骤 2：启动控制台并绑定账号
双击运行 **`start.command`**，系统将自动拉起服务并在浏览器中打开控制台：
- 控制台地址：`http://localhost:5173`
- 进到左侧 **「账号管理」** 页面，为要分发的平台扫码登录/绑定：
  - **知乎** (`type=9`)、**百家号** (`type=5`)、**今日头条** (`type=7`)、**搜狐号** (`type=8`)、**微博** (`type=11`)、**企鹅号** (`type=15`)、**百度贴吧** (`type=10`)
  - **网易号** (`type=13`)、**大鱼号** (`type=14`)、**微信公众号** (`type=12`)：待绑，绑定后自动进入候选池（根目录有对应的 `login_*.py` 辅助脚本）
  - **小红书** (`type=1`)：账号已封禁，**不要绑定、不要发布**
- 绑定状态以控制台账号管理页与本地数据库 `user_info` 表为准；发布入口脚本执行前会自动预检账号与 Cookie 状态。

### 步骤 3：让您的 AI Agent 接管内容生产
将下方话术复制给您的 AI Agent（推荐 Antigravity / Cursor / Windsurf / Claude Code），给出选题即可全自动一步到位生产发布。

## 二、 复制给 AI Agent 的执行话术

请直接复制以下内容发送给您的 AI Agent：

```markdown
请首先读取当前项目根目录下的 `AGENTS.md` 与 `REVIEW.md`。本项目是「河狸云·蓝枢 Planora」的一稿五投自媒体内容生产流水线，现行模式为「全自动发布」。

我的目标是针对我给出的选题，采用「全自动一步到位」模式：
1. 严格按照 AGENTS.md 规范撰写双版本正文（动态短图文 300~500字 + 长文平台通用精炼文 800~1100字），并为各平台定制专属合规标题与标签（注意各平台标题字数红线，杜绝任何违规词，勾选对应 AI 声明）；
2. 生成 6 张独立专版配图（3张 16:9 横图 + 3张 3:4 竖图），必须使用品牌标准资产目录下的正版河狸云 Logo 与真实产品截图，严禁 AI 假 Logo 与文字乱码框；
3. 发布前按 REVIEW.md 逐项过合规闸门，然后通过统一入口 `omnipost/scripts/publish_episode.py` 执行：从有效账号池随机抽取 5 个平台真实发布（小红书永久禁发、严禁选入），获取各平台公开链接；
4. 将发布记录写入本地 OmniPost 数据库（publish_drafts 与 publish_history，状态 published），并把链接回填飞书每日动作台账后回读校验；
5. 最终输出本期 5 个平台名单、公开链接、核验截图路径与台账回填结果。

请先做账号预检（或使用 --dry-run 只预检不发布）并向我汇报候选平台池，确认无误后我将提供接下来的核心选题。
```

## 三、 日常发布与运营节奏

1. **每天 1 篇**：Agent 全自动完成生产、合规自检、随机 5 平台发布与台账回填；人只需事后核对。
2. **核对入口**：本地面板 `http://localhost:5173/#/publish-history` 查看当期 5 个平台的发布记录与链接；飞书「GEO 每日动作台账」核对链接回填与完成数。发布失败的平台按汇报如实处理，不虚报。
3. **关闭服务**：不再使用时，双击运行 **`stop.command`** 即可安全退出所有后台进程。
